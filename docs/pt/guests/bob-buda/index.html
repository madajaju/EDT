Biography

Eu fundei a Buda Consulting há mais de duas décadas com a intenção de liderar o design e desenvolvimento de sistemas de banco de dados e me tornar um dos primeiros Administradores de Banco de Dados certificados pela Oracle. Nossa equipe de profissionais de banco de dados altamente qualificados e experientes conquistou uma posição entre os principais provedores de serviços de computador relacionados a bancos de dados nas áreas de Nova Jersey e Nova York, capacitando as empresas a proteger e otimizar o valor de seus dados.
