Andrew Amann

LinkedIn Profile

Biography

アンドリュー・アマンは、資金調達を受けたスタートアップや消費者レポート、シンプリセーフ、エクスペリアンなどの確立されたブランドのために製品を構築するAIコンサルティング会社、ナインツースリー・スタジオのCEOおよび共同創設者です。 過去12年間で、ナインツースリーはマイクロソフトやIBMと並んで米国のトップコンサルティングエージェンシー、トップモバイルアプリエージェンシー、そして4回のインク5000最も急成長している企業の賞を受賞しました。 アンドリューは確立された起業家であり、イントレプレナーです。彼は14の企業を創設し、3つの出口戦略を持ち、2つの特許を所有し、エージェンシーインテリジェンスコミュニティの創設者です。 ナインツースリーに入る前、アンドリューは原子力潜水艦のエンジニアとして働き、製造のためのサプライチェーン改善を発明し、2件の米国特許を取得しました。 アンドリューは18年間、投資のリターンを最大化するためにデジタルビジネスの構造について企業にアドバイスしてきました。彼はデジタルビジネスモデルとその運営方法を、複数の業界におけるデジタルトランスフォーメーションを実行する中で得た経験から認識しています。 アンドリューはAIがどこで有用かを深く理解しており、その技術を意味のある形で適用しています。ナインツースリーのプロジェクトは、投資回収が月単位ではなく週単位で発生することを実現しています。 AIは革新と成長のための強力なツールであり、ナインツースリー・スタジオはクライアントと世界のためにより良い未来を築くためにその力を活用することに尽力しています。 現在、アンドリューはすべてのタイプのビジネス向けのAIソリューションを開発するスピーカーおよびリーダーです。彼は8年間のAI経験を持ち、サプライチェーンのチャンピオンとして効率性とワークフロー自動化を見つけることに情熱を注いでいます。 仕事の外では、アンドリューはボストンのすぐ外で暮らしており、二人の子供と幸せに結婚しています。彼はまた、UConnのマスコットでもありました！
