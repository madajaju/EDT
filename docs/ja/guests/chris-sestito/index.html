Chris Sestito

LinkedIn Profile

Biography

クリス・セスティトは、さまざまな役割と業界にわたる多様な職務経験を持っています。2012年から2014年まで、彼はUS Foodsでテリトリーマネージャーとして働いていました。2015年には、The Media Trustでマルウェアアナリストとしての役割に移行し、その後Cylance Inc.に入社しました。ここでは、シニア脅威研究者、脅威研究のマネージャー、脅威研究のディレクターなど、複数のポジションを歴任しました。クリスは2020年にAgariでデータサイエンスのシニアディレクターとしてデータセキュリティの分野でキャリアを続けました。2021年にはQualysにエンジニアリング、データサイエンスのVPとして入社しました。最終的に、2022年にはHiddenLayerを共同設立し、現在はCEOを務めています。 クリス・セスティトは、コンピュータ情報システムとデータサイエンスに焦点を当てた多様な教育背景を持っています。2013年、彼はECPI大学に入学し、CISプログラム内でネットワークセキュリティの集中講義を履修しました。クリスは2015年までECPI大学で学び、ネットワークセキュリティに関する専門知識を得ました。2015年には、ネットワークセキュリティに集中したコンピュータ情報システムの準学士（A.S.）の学位をECPI大学から取得しました。 その後、クリスは2019年にテキサス大学オースティン校に通い、データサイエンス、分析、可視化に焦点を当てましたが、特定の学位プログラムについては言及されていません。学問の分野は明記されていないものの、この期間にデータ分析および可視化のスキルを発展させたと推測できます。 クリスはその他の資格も取得しています。2015年にはCompTIAからCompTIA Security+の認証を取得し、情報セキュリティに関する専門知識を強調しています。さらに、2016年6月にはEC-CouncilからCertified Ethical Hackerの認証を取得しました。これらの認証は、倫理的ハッキングおよび情報セキュリティの実践における彼の能力を示しています。 全体として、クリス・セスティトの教育は、コンピュータ情報システム、ネットワークセキュリティ、データサイエンス、データ可視化にわたっています。
