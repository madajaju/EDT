Biography

15年以上の新興技術企業におけるコンサルティブセールスとビジネス開発の経験を持ち、効果的な営業チームやチャネルを構築し維持することに優れた情熱的で意欲的なリーダーです。現在、Graid Technology Inc.のOEMおよびチャネルビジネス開発のシニアディレクターを務めており、革新的なNVMeソリューション、SupremeRAID™を用いて世界記録を打ち立てている企業です。このソリューションは高性能なワークロードの潜在能力を最大限に引き出します。 Graidでは、OEMおよびチャネルの営業戦略の開発と実行、主要なパートナーシップや関係の管理、市場の存在感や収益の拡大を担当しています。フラッシュメモリ、データストレージ、仮想化、クラウド、DevOps、コンテナ/Kubernetesに関する専門知識を活用して、顧客やパートナーに付加価値のあるソリューションを提供しています。また、年間数百万ドルの売上目標を超える実績や、権威ある賞を受賞し、エグゼクティブプレゼンテーションや公演を行う経験があります。
