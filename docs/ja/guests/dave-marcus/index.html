Biography

デイブ・マーカスはサイバーセキュリティ業界での長い歴史を持ち、実務者としても効果的なチームビルダーとしても知られています。彼は国際的にハッカーやサイバー脅威アクターについて効果的に調査し、標的にし、広く見られる脅威、APTグループや攻撃に基づく週次インテリジェンスサマリーを作成・提供し、独自の顧客インテリジェンス要件に基づいた数千のインテリジェンス製品やブリーフィングを提供してきました。以前はマカフィーおよびインテルセキュリティの最も尊敬されるプincipalエンジニアの一人として、インテリジェンス、検出方法論、データ分析のロードマップや技術的方向性を推進し、世界クラスのインテリジェンスチームを構築する手助けをしました。現在、インテルに戻り、彼は連邦チームでシニアセキュリティアーキテクトとして、政府の顧客と共に非常に重要な連邦業務に取り組んでいます。
